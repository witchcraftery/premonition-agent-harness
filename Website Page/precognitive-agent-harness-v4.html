V4 formal spec · spark tree · system layers

Precog Agent Harness

A formalized receding-horizon architecture where the visible model stays grounded in observed reality while a sparse branch system prepares for likely next events, escalates only when justified, and preserves a lineage of dormant possibilities.

System thesis

Preparation beats improvisation. The point is not to claim certainty about the future. The point is to maintain a compact, calibrated tree of near-futures so the system is ready when reality resolves.

Observed truth wins Sparse branch encoding Selective deep simulation Safety-gated action
Readiness equation
R(branch) = P(branch) × impact × usefulness − false-prep cost

The system should spend more compute only when a branch is both plausible and worth being ready for.

Spark tree view

How the branch tree lives, sleeps, and survives

The tree is intentionally shallow and sparse. Most branches stay dormant. One lineage becomes active only when the external world confirms it.

Top-K: 5 Horizon: 3 Escalation: selective
Root event

The external world presents an actual moment. This is the only hard ground truth the system starts from.

Dormant branch

A compact event hypothesis with probability, impact, trigger conditions, and a pointer to prepared artifacts. It stays cheap until evidence strengthens it.

Live lineage

One branch survives contact with reality. The next horizon is regenerated from here rather than from the whole tree.

Pruned path

Dead branches remain in lineage history for calibration and evaluation, but stop consuming forward compute.

The design goal is structural foresight with minimal tokens, not speculative storytelling.

Layered system model

The system’s cognition stack

Each layer has a different time orientation and a different relationship to uncertainty.

Layer 1 · now
Presenter / Face Agent

The visible model responds from current observed reality, checks prepared support first, and falls back to live reasoning when novelty is high.

  • User-facing response only
  • Consumes branch cache
  • Emits ground truth
  • Never surfaces speculation as fact
Layer 2 · near future
Swarm Readiness Engine

A top-k branch generator that prepares shallow, useful artifacts such as drafts, checks, fallbacks, and tool plans for likely next events.

  • Generates sparse next-event branches
  • Attaches low-cost readiness payloads
  • Scores expected value of preparation
  • Escalates only when justified
Layer 3 · possibility space
Probability World-Model Engine

A lineage-aware tree store that updates priors from actual outcomes, prunes dead branches, and optionally invokes richer simulation engines for hard cases.

  • Maintains live possibility tree
  • Preserves dormant lineage
  • Tracks calibration
  • Feeds ranked hypotheses back to the swarm
The presenter should not carry the whole future in working memory.
